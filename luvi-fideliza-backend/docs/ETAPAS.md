# Entregas do LUVI Fideliza+

0.1: base do banco e configuração.
0.2: administrador local, sessão, CSRF, estabelecimento, convite e isolamento.
0.3: programa de fidelidade por negócio, permissões, versões imutáveis e conflito de edição.

Próxima entrega funcional: participantes, cartões e crédito de carimbos com idempotência.
Depois: recompensas e resgate, painel web e aplicativo Flutter.

Pendências antes de piloto público: e-mail/verificação/recuperação, convites para
contas existentes, gestão da equipe, auditoria geral, limites de tentativas,
regras comerciais de plano/cortesia e revisão das dependências.

Mantemos Java 17 e Spring Boot 3.5.6 nesta entrega para preservar o ambiente
local validado; isso não representa homologação para exposição pública.
